## Resumo da vaga
A vaga pede uma pessoa júnior para criar e manter sites e landing pages, com foco em front-end web e consumo de APIs REST.  
Também exige domínio de HTML5, CSS3, JavaScript, Bootstrap, Git e GitHub, além de boa comunicação.  
React é desejável, mas não obrigatório.

## Lacunas
- Implementar páginas responsivas a partir do layout do time de design: sem evidência no material. Não há trecho dizendo que a candidata recebeu layout do time de design ou que implementou páginas responsivas a partir dele.
- Responsabilidade de implementar páginas responsivas: há menção a landing pages, mas não há evidência direta de trabalho a partir de layout de design nem de responsividade. [curriculo.pdf#p1c2]
- Boa comunicação com evidência direta para contexto profissional de colaboração com equipe/clientes: há indícios de escrita e comunicação, mas não há descrição direta de interação com clientes ou time em comunicação de trabalho. [curriculo.pdf#p1c1] [respostas_anteriores.md#c3]
