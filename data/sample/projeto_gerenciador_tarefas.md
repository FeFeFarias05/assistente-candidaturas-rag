# Projeto: Gerenciador de tarefas (perfil fictício)

## Visão geral
API e interface simples para gerenciar tarefas pessoais. Feito em Python com Flask e SQLite durante a disciplina de Engenharia de Software II, em dupla.

## O que eu fiz
- Desenhei o modelo de dados (usuário, tarefa, etiqueta) e escrevi as consultas em SQL.
- Implementei os endpoints REST de criação, listagem, edição e remoção de tarefas.
- Escrevi testes automatizados com pytest e cheguei a 85% de cobertura.
- Usei Git com branches por funcionalidade e revisão de pull request na dupla.

## Resultados
- 18 endpoints testados, sem falhas na entrega final.
- A professora destacou a clareza da documentação da API.

## O que não fiz
- Não usei Docker nem fiz deploy; rodou apenas localmente.
- Não implementei autenticação com tokens; o login era simples, por sessão.
