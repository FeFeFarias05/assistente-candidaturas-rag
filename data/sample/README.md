# Material de exemplo (FICTÍCIO)

"Ana Exemplo" e tudo o que está nestes arquivos são inventados, só para demonstrar e testar o projeto. Nenhum dado é real.

O perfil **não tem** de propósito: C#, jQuery, Docker, Kubernetes, Java e experiência em gestão administrativa. Vagas que pedem isso servem para testar se o sistema aponta a lacuna em vez de inventar experiência.

Para usar o seu material real, ponha os arquivos em `data/private/` (ignorado pelo Git) e aponte `MATERIAL_DIR` no `.env`.
