# Project: Expense Dashboard (fictional profile)

## Overview
Personal project to learn React. A single-page dashboard that shows monthly expenses with charts and filters. It fetches data from a small REST API I wrote in Flask.

## What I did
- Built the interface with React (function components and hooks) and plain CSS.
- Consumed the REST API with fetch, handling loading and error states.
- Created reusable components: expense card, category filter and monthly chart.
- Wrote the README in English and published the code on GitHub.

## Results
- About 6 months of part-time work, around 10 hours a week.
- It is a learning project: no users and no production deployment.

## Gaps
- I have used React only in this project, for about 6 months.
- I did not write automated tests for the React components.
- I have not used Redux or any state library beyond hooks.
